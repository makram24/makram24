## About me

I'm a full-stack developer and **MSc Computer Science Engineering student at Budapest University of Technology and Economics (BME)**, based in Budapest, Hungary.

My work spans **React/TypeScript interfaces, Node.js services, Firebase-backed products, AI agent workflows, the Model Context Protocol (MCP), and IoT/smart-city applications**. I enjoy turning real requirements into usable end-to-end systems, with particular attention to developer experience, testing, and clear technical documentation.

- **Software engineering:** full-stack web apps, APIs, authentication, dashboards and workflows
- **AI & automation:** agent-assisted code review, MCP integrations and ML experimentation
- **Research interests:** IoT, intelligent systems, connected cities and enterprise integration
- **Open to:** software engineering roles, technical collaboration and research opportunities
